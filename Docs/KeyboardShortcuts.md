# Keyboard shortcuts

## Browse (macOS)

| Key | Action |
|-----|--------|
| ⌘⇧B | Open browse sidebar / sheet |
| ↑ / ↓ | Move focus in sidebar or catalog (when focus coordinator active) |
| Return | Activate selected row |
| E | Back / dismiss detail |

## Playback (macOS)

| Key | Action |
|-----|--------|
| Space | Play / pause |
| Esc | Exit player |
| N | Next episode |
| P | Previous episode |
| , | Back 10 seconds |
| . | Forward 10 seconds |

## Apple TV (future)

Same logical map; focus engine and Siri Remote mapping deferred until tvOS target.
